# 데굴데굴 시간공작소

시간 구슬을 굴려 작은 손도구부터 미래의 거대한 생태돔까지 모으는 한국어 3D 웹게임입니다. 제조, 건설, 수송, 통신, 생명의 다섯 주제를 시대 순서로 경험하도록 구성했습니다.

## 게임 특징

- 외부 3D 런타임 없이 브라우저 WebGL로 렌더링
- 방향키/WASD, 부스터, 브레이크, 일시정지, 전체화면 지원
- 모바일 터치 조이스틱과 부스터 지원
- 물건을 모을수록 커지는 시간 구슬과 다섯 시대 진행
- 시대별 제한 시간, 재도전, 로컬 최고 기록 저장
- 화면 움직임 줄이기와 고대비 환경 설정 지원
- 자동 검증을 위한 `window.render_game_to_text`와 `window.advanceTime`

## 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

프로덕션 검증:

```bash
npm run build
npm run lint
npx tsc --noEmit
node --test tests/rendered-html.test.mjs
```

로컬에 Playwright가 준비된 환경에서는 `scripts/game-e2e.mjs`로 데스크톱 전체 시대 플레이와 모바일 터치 조작을 검증할 수 있습니다.

## 창작 원칙

이 프로젝트는 구체를 굴려 작은 물건부터 모으며 성장하는 장르의 핵심 규칙만 활용합니다. 특정 상용 게임의 캐릭터, 이름, 음악, UI, 레벨, 그래픽 자산은 복제하지 않았으며 시간정비 로봇 `토리`, 시간 구슬, 시대별 발명품 세계는 모두 이 프로젝트를 위해 새로 구성했습니다.
